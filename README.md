# perm-u65

Одностраничный сайт ТСЖ «Адмирала Ушакова, 65» (Пермь). Содержимое перенесено с ushakova65.ru.

Статический сайт без сборки: откройте `index.html` в браузере. Все библиотеки лежат в проекте, внешние CDN не нужны.

## Структура

```
index.html            страница
css/style.css         оформление (цвета — переменные в :root)
js/main.js            меню, прокрутка, анимации
assets/img/           логотип, фото, иконки сайта
assets/docs/          планировки квартир по подъездам (PDF)
data/                 данные для блока новостей
vendor/               Bootstrap 5.3.3, Bootstrap Icons 1.11.3, шрифт Manrope
```

## Блок новостей (импорт из MAX — позднее)

Сейчас в блоке `#news` только каркас: заглушки-скелетоны и шаблон карточки.

Точки подключения для импорта:
- `#news-list` — контейнер карточек; атрибут `data-source` указывает источник данных (`data/news.json`);
- `<template id="news-card-template">` — разметка одной новости, поля помечены `data-news-*`
  (`date`, `title`, `text`, `image`, `link`);
- `#news-empty` — сообщение, когда новостей нет.

Формат записи — в `data/news.example.json`.
